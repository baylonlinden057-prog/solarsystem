# 🌌 Midterm Project – Interactive Solar System

This project was created as part of the **Midterm Project for Computer Graphics Programming** at **Gordon College – College of Computer Studies (CCS)**.

The project is an **interactive Solar System visualization** that demonstrates the concepts, techniques, and programming principles discussed in our Computer Graphics Programming course. It showcases the planets, their orbital movement, and the overall structure of the Solar System through an interactive graphical environment.

The project was developed as a midterm requirement and serves as an application of computer graphics concepts, including **3D visualization, object modeling, animation, transformations, lighting, camera perspectives, and interactive graphics**.

## ☀️ Project Description

The Interactive Solar System presents a graphical representation of our Solar System, featuring the **Sun and the planets** arranged according to their position and orbital paths.

The project aims to provide an engaging way to visualize planetary motion and demonstrate how computer graphics can be used to create an interactive 3D environment.

Users can explore the Solar System through the graphical interface and observe the planets and their movements within the simulated environment.

## ✨ Features

- ☀️ Sun and planetary system visualization
- 🪐 Multiple planets with individual characteristics
- 🔄 Planetary orbital animation
- 🌌 3D space environment
- 🎥 Interactive camera perspective
- 💡 Lighting and visual effects
- 🖱️ Interactive controls
- 🌍 Realistic orbital arrangement and movement
- 📐 Application of computer graphics transformations
